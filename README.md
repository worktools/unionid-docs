# unionid documentation

The bilingual documentation site for [unionid](https://github.com/worktools/unionid), built with VitePress.

## Development

```bash
npm install
npm run docs:dev
```

## Build

```bash
npm run docs:build
npm run docs:preview
```

Chinese is the default locale. English content lives under `docs/en/`; keep matching pages aligned when changing user-facing behavior or examples.
